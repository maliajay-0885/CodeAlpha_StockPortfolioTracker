\# CodeAlpha Stock Portfolio Tracker



\## Project Description



A Python program that calculates the total investment value of a stock portfolio using predefined stock prices.



\## Features



\- Displays available stocks and their prices.

\- Accepts stock symbols and quantities from the user.

\- Calculates individual stock investment values.

\- Calculates the total portfolio investment.

\- Saves the portfolio summary to `portfolio.txt`.

\- Handles invalid stock symbols and quantities.



\## Technologies Used



\- Python

\- Dictionaries

\- Loops and conditional statements

\- User input and file handling



\## How to Run



1\. Install Python.

2\. Open this project folder in PowerShell.

3\. Run `python main.py`.

4\. Enter a stock symbol and quantity.

5\. Enter `DONE` when finished.



\## Note



The stock prices are predefined example values and are not live market prices.
